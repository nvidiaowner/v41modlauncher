# v41mod 启动器

[打开稳定版下载页](https://github.com/nvidiaowner/v41modlauncher/releases/latest)

**已有启动器：** 退出游戏，打开启动器，点击右上角「检查更新」。选择「更新至 …」并确认。启动器验签后切换版本，保留账号、连接配置和游戏资源。

**首次安装：** 从下载页获取 `v41mod-launcher-base-win-x64.zip`，解压后打开顶层 `v41mod-Launcher.exe`。首次进游戏仍需维护者提供的连接配置和原版九个 SOL 资源包。程序更新 ZIP 和签名清单供启动器自动使用，无需手动下载，也不能用于首装。
